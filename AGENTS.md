# AGENTS.md

Personal finance SPA. React 19 + TypeScript + Vite. The REST API (Java/Spring Boot) lives in a separate repo and is expected at `http://localhost:8080`. UI copy is pt-BR with no i18n layer.

## Commands

Node 24 / npm 11 (`.nvmrc`, `engines`).

- `npm run dev` — Vite on `:5173`; `/api` proxied to `localhost:8080`.
- `npm run dev:mock` — same, with MSW browser mocks and demo session. Login: `ana@example.com` / `secret`.
- `npm test` — all Vitest tests.
- `npx vitest run src/App.test.tsx` — one file; add `-t "test name"` for one test.
- `npm run lint`, `npm run typecheck`, `npm run build` (`tsc -b` then Vite).
- `npm run format` / `npm run format:check` — Prettier: no semicolons, single quotes, width 100.
- CI (`.github/workflows/ci.yml`) runs, in order: `npm ci`, `lint`, `typecheck`, `test`, `build`. Match that order before finishing.

## Wiring and conventions

- Entry: `src/main.tsx` → `src/App.tsx` → `AppProviders` + `BrowserRouter` → `AppRoutes`.
- Routes are navigation-driven. `src/app/app-routes.tsx` auto-creates "Em breve" routes for `navigationItems` with `available: false`. Flipping `available: true` in `src/app/navigation.ts` alone gives no route; add an explicit `<Route>`.
- `@/*` maps to `src/*` (Vite and tsconfig). Router imports come from `react-router`, not `react-router-dom`.
- Query defaults: `retry: false`, no refetch on window focus. Auth state uses query key `['auth', 'me']`; logout removes all non-auth queries. Give domain queries their own keys.
- HTTP goes through `apiRequest` in `src/lib/api/client.ts`: `VITE_API_URL` (default `/api/v1`), `credentials: 'include'`, `X-XSRF-TOKEN` from the `XSRF-TOKEN` cookie on mutating methods, RFC 9457 errors as `ApiError`. Add endpoints in `features/<domain>/api.ts`, not with raw `fetch`.
- `openapi-fetch` / `openapi-typescript` are installed but unused; types are hand-written because the OpenAPI contract does not exist yet.
- Money is integer cents; dates are ISO 8601 strings.
- TypeScript uses `verbatimModuleSyntax` (use `import type`) and rejects unused locals/parameters. Do not relax compiler options.
- UI: Tailwind 4 + shadcn/ui (`components.json`, style `radix-nova`). Add primitives under `src/components/ui`; use `cn` from `src/lib/utils.ts`.

## Tests

- Vitest + React Testing Library + MSW. `src/test/setup.ts` starts the MSW node server, resets handlers after each test, clears `localStorage` and the `dark` class, and stubs `matchMedia`, `ResizeObserver`, and `scrollIntoView`.
- Tests are colocated as `*.test.tsx`. Render full flows with `AppProviders` + `MemoryRouter` (see `src/features/auth/auth-flow.test.tsx`).
- Override endpoints per test with `server.use(...)` from `@/test/msw/server`; reuse `demoUser` from `@/mocks/handlers`.
- Browser and node mocks share `src/mocks/handlers.ts`. `public/mockServiceWorker.js` is generated by MSW; do not edit it. Mocks only start when `import.meta.env.DEV` and `VITE_ENABLE_MSW=true`.
- Assertions target Portuguese UI text.
